# INTRO: Nota ricorrente: ogni classe grafica contiene `private static final long serialVersionUID = 1L;`. I componenti Swing sono "serializzabili" (salvabili come byte) e Java raccomanda di dichiarare un numero di versione; nel programma non si usa questa funzione, la riga serve solo a evitare un avviso del compilatore.
