Comandi IOS essenziali

Modalità

Router> user EXEC → enable → Router# privileged EXEC → configure terminal → Router(config)# → interface g0/0 → Router(config-if)#

Base

hostname R1
enable secret Cisco123!
no ip domain-lookup
banner motd # Accesso riservato #
line console 0
 password cisco
 login
 logging synchronous
interface g0/0
 description Link verso SW1
 ip address 192.168.1.1 255.255.255.0
 no shutdown
copy running-config startup-config
