Metodo del magic number

  1. Trova l'ottetto interessante: quello in cui la maschera non è né 255 né 0.
  2. Block size = 256 - valore della maschera in quell'ottetto.
  3. Le subnet iniziano dai multipli del block size: 0, B, 2B, 3B...
  4. La rete dell'host è il multiplo immediatamente inferiore o uguale al suo valore.
  5. Broadcast = subnet successiva - 1. Host: da rete+1 a broadcast-1.

Esempio: 172.16.45.130/27 → maschera .224 → block 32 → subnet .128 (128-159) → rete 172.16.45.128, broadcast 172.16.45.159, host .129-.158.

Formule

  • Numero di subnet = 2bit presi in prestito
  • Host per subnet = 2bit di host - 2
  • Potenze di 2: 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048, 4096
