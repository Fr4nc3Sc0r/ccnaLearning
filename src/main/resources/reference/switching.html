Trunk 802.1Q

  • Tag di 4 byte (TPID 0x8100, PCP, DEI, VLAN ID 12 bit). Native VLAN non taggata.
  • switchport trunk allowed vlan add 30 (senza "add" sostituisci la lista!)
  • Best practice: native VLAN inutilizzata, switchport nonegotiate.

Spanning Tree (Rapid PVST+)

  1. Elezione root bridge: Bridge ID più basso (priorità multipla di 4096 + VLAN ID, poi MAC).
  2. Root port su ogni non-root: costo verso il root più basso → BID del vicino più basso → port ID più basso.
  3. Designated port su ogni segmento; le altre diventano alternate/backup (discarding).

Stati 802.1D: blocking, listening (15 s), learning (15 s), forwarding, disabled. RSTP: discarding, learning, forwarding.

Timer 802.1D: hello 2 s, forward delay 15 s, max age 20 s.

  • PortFast: porta edge, va subito in forwarding (solo verso host).
  • BPDU Guard: err-disable se arriva una BPDU.
  • Root Guard: impedisce che un dispositivo sulla porta diventi root.
