QoS

  • Classificazione e marcatura: CoS (802.1p, 3 bit L2), DSCP (6 bit L3). EF = 46 (voce), AF41 = 34, CS0 = 0.
  • Trust boundary: il punto in cui ci si fida delle marcature (di solito il telefono IP o lo switch di accesso).
  • Code: LLQ (priorità stretta) + CBWFQ (banda garantita).
  • Congestion avoidance: WRED. Policing scarta/rimarca, shaping mette in buffer.
  • Voce: one-way delay ≤ 150 ms, jitter ≤ 30 ms, perdita ≤ 1%.
