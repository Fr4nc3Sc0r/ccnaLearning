OSPFv2 single-area

Concetti chiave

  • Link-state, algoritmo SPF (Dijkstra), AD 110, metrica = costo.
  • Costo = reference bandwidth (default 100 Mbps) / bandwidth dell'interfaccia.
  • Pacchetti: Hello, DBD, LSR, LSU, LSAck. Multicast 224.0.0.5 (tutti i router OSPF) e 224.0.0.6 (DR/BDR).
  • Timer di default su broadcast e point-to-point: hello 10 s, dead 40 s.

Router ID

  1. Comando router-id
  2. IP più alto tra le loopback attive
  3. IP più alto tra le interfacce fisiche attive

Requisiti per l'adiacenza

Devono coincidere: area, subnet/maschera, hello/dead, autenticazione, stub flag, MTU (per FULL). Il router ID deve essere unico. Il process ID è locale.

Stati del vicino

Down → Init → 2-Way → ExStart → Exchange → Loading → Full

Bloccato in ExStart/Exchange → MTU diversa. 2-Way tra due DROTHER è normale.

DR / BDR

  • Eletti su reti broadcast/NBMA; priorità più alta vince (default 1), poi RID più alto.
  • Priorità 0 = mai DR/BDR. Elezione non preemptive.
  • Su point-to-point (ip ospf network point-to-point) nessuna elezione.

LSA principali

Type 1 Router · Type 2 Network (generato dal DR) · Type 3 Summary (ABR) · Type 5 External (ASBR)

Configurazione

router ospf 1
 router-id 1.1.1.1
 network 10.0.12.0 0.0.0.3 area 0
 passive-interface GigabitEthernet0/2
 auto-cost reference-bandwidth 100000
 default-information originate
!
interface GigabitEthernet0/1
 ip ospf 1 area 0
 ip ospf network point-to-point
 ip ospf cost 10
 ip ospf priority 100
