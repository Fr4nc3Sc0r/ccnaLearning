Regole di compressione

  • Togli gli zeri iniziali di ogni hextet (0DB8 → DB8), mai quelli finali.
  • Sostituisci una sola sequenza di hextet a zero con :: (la più lunga).

EUI-64

MAC 0011.2233.4455 → 0011:22FF:FE33:4455 → inverti il 7° bit → 0211:22FF:FE33:4455
