[Q]
id: IPC-001
domain: 3
type: SINGLE
text:
Refer to the exhibit. R1 receives a packet destined to 10.1.1.70. Which next hop does R1 use to forward the packet?
exhibit:
R1#show ip route
Gateway of last resort is 203.0.113.1 to network 0.0.0.0

S*    0.0.0.0/0 [1/0] via 203.0.113.1
      10.0.0.0/8 is variably subnetted, 4 subnets, 4 masks
O        10.1.0.0/16 [110/20] via 192.168.1.2, 00:12:10, GigabitEthernet0/1
D        10.1.1.0/24 [90/30720] via 192.168.2.2, 00:05:33, GigabitEthernet0/2
S        10.1.1.0/25 [1/0] via 192.168.4.2
R        10.1.1.64/26 [120/2] via 192.168.3.2, 00:00:12, GigabitEthernet0/3
options:
A) 192.168.1.2
B) 192.168.2.2
C) 192.168.3.2
D) 192.168.4.2
answer: C
explanation:
Il router sceglie SEMPRE la corrispondenza più specifica (longest prefix match), indipendentemente da AD e metrica.
10.1.1.70 corrisponde a: /16, /24, /25 (0-127) e /26 (64-127). Il prefisso più lungo è 10.1.1.64/26 → next hop 192.168.3.2 via RIP.
AD e metrica servono solo a scegliere tra route verso lo STESSO prefisso con la stessa lunghezza.
reference: Exam topic 3.2 - Determine how a router makes a forwarding decision by default (longest prefix match)
[/Q]

[Q]
id: IPC-004
domain: 3
type: SINGLE
text:
A router learns a default route through OSPF. The network engineer wants to configure a backup default route to 198.51.100.1 that is used only if the OSPF route is lost. Which command should be used?
options:
A) ip route 0.0.0.0 0.0.0.0 198.51.100.1
B) ip route 0.0.0.0 0.0.0.0 198.51.100.1 100
C) ip route 0.0.0.0 0.0.0.0 198.51.100.1 115
D) ip route 0.0.0.0 255.255.255.255 198.51.100.1 130
answer: C
explanation:
Una floating static route ha un'AD maggiore di quella della route primaria: deve essere > 110 (OSPF) per restare inattiva finché la route OSPF esiste. L'unica scelta valida è AD 115 con la maschera 0.0.0.0.
Con AD 1 (default) o 100 la statica prevarrebbe su OSPF; la maschera 255.255.255.255 indicherebbe una host route, non una default.
reference: Exam topic 3.3.d - Floating static
[/Q]

[Q]

domain: 3
type: SINGLE
text:
Refer to the exhibit. Four routers are connected to the same Ethernet segment and the OSPF processes start simultaneously. Which router becomes the DR?
exhibit:
Router   OSPF priority   Router ID
R1       1               10.0.0.4
R2       10              1.1.1.1

[Q]

With the default OSPF reference bandwidth (100 Mbps), what is the OSPF cost of a 10 Mbps Ethernet interface? (Enter a number.)

[Q]
id: IPC-010
domain: 3
type: SINGLE
text:
A router interface is configured with IP address 172.16.5.9/30. Which network command enables OSPF area 0 on this interface only, without matching any other address?
options:
A) network 172.16.5.8 0.0.0.3 area 0
B) network 172.16.5.9 0.0.0.0 area 0
C) network 172.16.0.0 0.0.255.255 area 0
D) network 172.16.5.9 255.255.255.252 area 0
answer: B
explanation:
Il comando "network" usa una wildcard mask: 0.0.0.0 significa "corrispondenza esatta di questo indirizzo", quindi abilita OSPF solo sull'interfaccia con 172.16.5.9. Con 172.16.5.8 0.0.0.3 si includerebbero anche altri indirizzi del /30; usare 255.255.255.252 è un errore, perché il comando richiede una wildcard e non una subnet mask.
Alternativa moderna: configurare "ip ospf 1 area 0" direttamente sull'interfaccia.
reference: Exam topic 3.4 - Configure and verify single area OSPFv2
[/Q]
