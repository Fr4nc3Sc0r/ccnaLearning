%CDP-4-NATIVE_VLAN_MISMATCH: Native VLAN mismatch discovered on

id: NA-003

Which two statements about IEEE 802.1Q trunking are true?
options:
A) It encapsulates the entire original frame in a new header.
B) It inserts a 4-byte tag into the Ethernet frame.
C) Frames in the native VLAN are sent untagged by default.
D) It supports a maximum of 1024 VLANs.
E) It is a Cisco-proprietary protocol.
answer: B, C

Which RSTP port role provides an alternate path to the root bridge and becomes the root port if the current root port fails?

A) To err-disable a PortFast port that receives any BPDU
B) To prevent a switch connected to the port from becoming the root bridge by blocking the port if it receives superior BPDUs
C) To speed up convergence after a root port failure
D) To prevent unidirectional link failures
answer: B
explanation:
Root Guard si applica sulle porte designated verso switch che non devono mai diventare root (es. switch di accesso o di clienti).
