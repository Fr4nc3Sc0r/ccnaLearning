[Q]
id: NA-001
domain: 2
type: SINGLE
text:
Refer to the exhibit. Which issue does the log message indicate?
exhibit:
%CDP-4-NATIVE_VLAN_MISMATCH: Native VLAN mismatch discovered on
GigabitEthernet0/1 (1), with SW2 GigabitEthernet0/1 (99).
options:
A) The trunk is not allowed to carry VLAN 99.
B) The native VLAN configured on the two ends of the trunk is different.
C) DTP failed to negotiate a trunk.
D) VTP domain names do not match.
answer: B
explanation:
CDP segnala che la native VLAN locale (1) è diversa da quella del vicino (99). Il traffico untagged inviato su un lato finisce nella VLAN sbagliata sull'altro lato (VLAN leaking), con possibili problemi STP. Soluzione: "switchport trunk native vlan 99" su entrambi i lati.
reference: Exam topic 2.2 - Configure and verify interswitch connectivity (native VLAN)
[/Q]

[Q]
id: NA-002
domain: 2
type: SINGLE
text:
Two switches are connected. Both interfaces are configured with "switchport mode dynamic auto". What is the resulting operational mode of the link?
options:
A) Trunk
B) Access
C) The link is err-disabled
D) Trunk with native VLAN 1 only
answer: B
explanation:
DTP: "dynamic auto" risponde alle richieste di trunk ma non le avvia. Se entrambi i lati sono auto, nessuno inizia la negoziazione → il link resta in access.
Combinazioni che formano un trunk: desirable+desirable, desirable+auto, trunk+auto, trunk+desirable, trunk+trunk.
Best practice: configurare i trunk staticamente e disabilitare DTP con "switchport nonegotiate".
reference: Exam topic 2.2 - Trunk ports / DTP
[/Q]

[Q]
id: NA-003
domain: 2
type: MULTI
text:
Which two statements about IEEE 802.1Q trunking are true?
options:
A) It encapsulates the entire original frame in a new header.
B) It inserts a 4-byte tag into the Ethernet frame.
C) Frames in the native VLAN are sent untagged by default.
D) It supports a maximum of 1024 VLANs.
E) It is a Cisco-proprietary protocol.
answer: B, C
explanation:
802.1Q (standard IEEE) inserisce un tag di 4 byte tra MAC sorgente e EtherType: TPID 0x8100 + PCP (3 bit, priorità CoS) + DEI + VLAN ID a 12 bit (4094 VLAN utilizzabili). Il traffico della native VLAN viaggia senza tag.
ISL era il protocollo proprietario Cisco che incapsulava l'intero frame (opzione A).
reference: Exam topic 2.2.a - Trunk ports (802.1Q)
[/Q]

[Q]
id: NA-004
domain: 2
type: SINGLE
text:
Refer to the exhibit. All switches run Rapid PVST+ with default settings except for the priorities shown. Which switch becomes the root bridge for VLAN 1?
exhibit:
Switch   Bridge priority   MAC address
SW1      32769             0011.1111.1111
SW2      24577             0022.2222.2222
SW3      24577             0033.3333.3333
SW4      32769             0000.0000.0001
options:
A) SW1
B) SW2
C) SW3
D) SW4
answer: B
explanation:
Il root bridge è quello con il Bridge ID più basso. Il BID = priorità (+ VLAN ID con extended system ID) e, a parità, il MAC address più basso.
SW2 e SW3 hanno la priorità più bassa (24577 = 24576 + VLAN 1). A parità di priorità vince il MAC più basso: 0022.2222.2222 < 0033.3333.3333 → SW2.
SW4 ha il MAC più basso di tutti ma la priorità viene confrontata prima.
reference: Exam topic 2.5 - Rapid PVST+ (root bridge election)
[/Q]

[Q]
id: NA-005
domain: 2
type: SINGLE
text:
Which RSTP port role provides an alternate path to the root bridge and becomes the root port if the current root port fails?
options:
A) Designated port
B) Backup port
C) Alternate port
D) Disabled port
answer: C
explanation:
Ruoli RSTP:
- Root port: miglior percorso verso il root (uno per switch non-root)
- Designated port: porta che inoltra su un segmento
- Alternate port: percorso alternativo verso il root, ricevuto da un altro switch (bloccata, pronta a subentrare)
- Backup port: percorso ridondante verso un segmento in cui lo switch è già designated (raro, es. hub)
Stati RSTP: discarding, learning, forwarding.
reference: Exam topic 2.5.a - Root port, root bridge, and other port names
[/Q]

[Q]
id: NA-006
domain: 2
type: SINGLE
text:
An access port is configured with "spanning-tree portfast" and "spanning-tree bpduguard enable". What happens if the port receives a BPDU?
options:
A) The port transitions to the blocking state and recovers automatically.
B) The port loses its PortFast status but continues forwarding.
C) The port is placed in the err-disabled state.
D) The BPDU is silently dropped.
answer: C
explanation:
BPDU Guard protegge le porte edge: se arriva una BPDU (qualcuno ha collegato uno switch), la porta va in err-disabled. Si ripristina con "shutdown"/"no shutdown" oppure automaticamente con "errdisable recovery cause bpduguard".
Senza BPDU Guard, una porta PortFast che riceve BPDU perde semplicemente lo stato di edge port (comportamento dell'opzione B).
reference: Exam topic 2.5.b - PortFast and its benefits / BPDU Guard
[/Q]

[Q]
id: NA-007
domain: 2
type: SINGLE
text:
Which combination of EtherChannel modes on two connected switches successfully forms a bundle?
options:
A) passive / passive
B) auto / active
C) active / passive
D) on / active
answer: C
explanation:
LACP (IEEE 802.3ad): active avvia la negoziazione, passive risponde. Formano un canale: active/active e active/passive. passive/passive no.
PAgP (Cisco): desirable/desirable e desirable/auto.
"on" forza il canale senza negoziazione e funziona solo con "on" dall'altra parte. Non si possono mischiare LACP e PAgP (auto/active).
reference: Exam topic 2.4 - Configure and verify (Layer 2/Layer 3) EtherChannel (LACP)
[/Q]

[Q]
id: NA-009
domain: 2
type: SINGLE
text:
Which statement about LLDP is true?
options:
A) It is a Cisco-proprietary protocol enabled by default on all Cisco devices.
B) It is an IEEE 802.1AB standard protocol and must be enabled globally with "lldp run" on many Cisco IOS devices.
C) It operates at Layer 3 and requires IP addressing.
D) It can discover devices that are more than one hop away.
answer: B
explanation:
LLDP (IEEE 802.1AB) è lo standard vendor-neutral di discovery; CDP è proprietario Cisco ed è attivo di default. Entrambi lavorano a Layer 2 e vedono solo i vicini direttamente connessi.
Comandi: "lldp run" (globale), "lldp transmit" / "lldp receive" (interfaccia), "show lldp neighbors [detail]". Per CDP: "cdp run", "show cdp neighbors detail".
Timer LLDP di default: 30 s invio, holdtime 120 s. CDP: 60 s / 180 s.
reference: Exam topic 2.3 - Configure and verify Layer 2 discovery protocols (CDP and LLDP)

text:
Using the short (16-bit) spanning-tree path cost method, what is the default port cost of a 100 Mbps (FastEthernet) link? (Enter a number.)
answer: 19
explanation:
Costi STP "short" (IEEE 802.1D-1998): 10 Mbps = 100, 100 Mbps = 19, 1 Gbps = 4, 10 Gbps = 2.
Il root path cost è la somma dei costi delle porte di ingresso lungo il percorso verso il root. Con il metodo "long" (32 bit) i valori sono 2.000.000 / 200.000 / 20.000 / 2.000.

Which statement about autonomous APs compared to lightweight APs is true?
