In a controller-based network, which interface does an application use to communicate with the SDN controller?
options:
A) Southbound API
B) Northbound API
C) Eastbound API
D) Console port
answer: B
explanation:
Northbound API: tra controller e applicazioni/script (tipicamente REST con JSON). Southbound API: tra controller e dispositivi di rete (es. NETCONF, RESTCONF, OpenFlow, OpFlex, SSH/CLI). Eastbound/westbound collegano controller tra loro.
