[Q]
id: NF-001
domain: 1
type: SINGLE
text:
At which layer of the OSI model does a switch make forwarding decisions based on MAC addresses?
options:
A) Layer 1 - Physical
B) Layer 2 - Data Link
C) Layer 3 - Network
D) Layer 4 - Transport
answer: B
explanation:
Uno switch (Layer 2) costruisce la MAC address table imparando gli indirizzi MAC sorgente dei frame e inoltra in base al MAC di destinazione. I router lavorano a Layer 3 (indirizzi IP), gli hub a Layer 1.

Chicca: uno switch "multilayer" (Layer 3 switch) può anche instradare tra VLAN tramite SVI, ma la commutazione dei frame resta una funzione Layer 2.
reference: Exam topic 1.1.b - Layer 2 and Layer 3 switches
[/Q]

[Q]
id: NF-002
domain: 1
type: MULTI
text:
Which two statements describe characteristics of UDP?
options:
A) It establishes sessions with a three-way handshake.
B) It is connectionless.
C) It provides flow control by using windowing.
D) It has a smaller header than TCP (8 bytes).
E) It guarantees delivery by retransmitting lost segments.
answer: B, D
explanation:
UDP è connectionless, non numera i segmenti, non ritrasmette e non fa controllo di flusso: per questo l'header è di soli 8 byte (porta sorgente, porta destinazione, lunghezza, checksum). TCP invece ha un header di almeno 20 byte, three-way handshake, sequence/acknowledgment number, windowing e ritrasmissione.

Usi tipici di UDP: DNS (query), DHCP, TFTP, SNMP, Syslog, VoIP/streaming (dove un pacchetto in ritardo è inutile).
reference: Exam topic 1.5 - Compare TCP to UDP
[/Q]

id: NF-005

text:
Which option is the correctly compressed form of the IPv6 address 2001:0DB8:0000:0000:0000:FF00:0042:8329?
options:
A) 2001:DB8::FF00:42:8329
B) 2001:DB8:0:0:FF00::42:8329
C) 2001:DB8::FF:42:8329

A switch receives a unicast frame whose destination MAC address is not in its MAC address table. What does the switch do?
