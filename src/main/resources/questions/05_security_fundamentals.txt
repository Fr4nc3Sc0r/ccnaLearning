[Q]
id: SEC-001
domain: 5
type: SINGLE
text:
According to Cisco best practices, where should a standard IPv4 ACL be placed?
options:
A) As close to the source as possible
B) As close to the destination as possible
C) On the Internet edge only
D) On every interface in the path
answer: B
explanation:
Le ACL standard filtrano solo per IP sorgente: se messe vicino alla sorgente bloccherebbero quel traffico verso TUTTE le destinazioni. Vanno quindi vicino alla destinazione.
Le ACL estese (sorgente, destinazione, protocollo, porte) vanno vicino alla sorgente per scartare il traffico indesiderato il prima possibile.
reference: Exam topic 5.6 - Configure and verify access control lists
[/Q]

[Q]
id: SEC-002
domain: 5
type: SINGLE
text:
Refer to the exhibit. The ACL is applied inbound on the router interface connected to the 192.168.10.0/24 LAN. What is the result?
exhibit:
ip access-list extended WEB
 10 permit tcp 192.168.10.0 0.0.0.255 host 10.0.0.5 eq 443
 20 deny ip 192.168.10.0 0.0.0.255 host 10.0.0.5
!
interface GigabitEthernet0/1
 ip address 192.168.10.1 255.255.255.0
 ip access-group WEB in
options:
A) LAN hosts can reach 10.0.0.5 using HTTPS and can reach all other destinations.
B) LAN hosts can reach 10.0.0.5 only using HTTPS, and all other traffic from the LAN is denied.
C) LAN hosts can ping 10.0.0.5 but cannot use HTTPS.
D) All traffic from the LAN is permitted because the deny statement comes last.
answer: B
explanation:
Le ACL sono elaborate dall'alto in basso e si fermano alla prima corrispondenza. La riga 10 permette HTTPS verso 10.0.0.5, la riga 20 nega il resto verso 10.0.0.5, e alla fine c'è sempre un "deny any" implicito: TUTTO il resto del traffico (es. Internet) viene scartato.
Per permettere il resto servirebbe "30 permit ip any any".
reference: Exam topic 5.6 - Access control lists (implicit deny)
[/Q]

[Q]
id: SEC-003
domain: 5
type: FILL
text:
What wildcard mask matches all addresses in the 172.16.32.0/20 network? (Enter in dotted-decimal format.)
answer: 0.0.15.255
explanation:
Wildcard = 255.255.255.255 - subnet mask. /20 = 255.255.240.0 → 255.255.255.255 - 255.255.240.0 = 0.0.15.255.
Nella wildcard, 0 = "il bit deve corrispondere", 1 = "bit indifferente". Casi speciali: "host 10.1.1.1" = 10.1.1.1 0.0.0.0; "any" = 0.0.0.0 255.255.255.255.
reference: Exam topic 5.6 - ACL wildcard masks
[/Q]

[Q]
id: SEC-004
domain: 5
type: SINGLE
text:
Which port security violation mode drops frames from unknown MAC addresses, increments the violation counter, and generates a syslog message, but keeps the port up?
options:
A) protect
B) restrict
C) shutdown
D) shutdown vlan
answer: B
explanation:
- protect: scarta, nessun log, nessun incremento contatore
- restrict: scarta, invia log/SNMP trap e incrementa il contatore; la porta resta up
- shutdown (default): la porta va in err-disabled
Comandi: "switchport port-security", "switchport port-security maximum 2", "switchport port-security mac-address sticky", "switchport port-security violation restrict". La porta deve essere access o trunk statico (non dynamic).
reference: Exam topic 5.7 - Configure and verify Layer 2 security features (port security)
[/Q]

[Q]
id: SEC-005
domain: 5
type: SINGLE
text:
With DHCP snooping enabled, which switch ports should be configured as trusted?
options:
A) All access ports connected to end users
B) Ports that lead toward legitimate DHCP servers, such as uplinks
C) Only ports in the native VLAN
D) No ports; DHCP snooping trusts all ports by default
answer: B
explanation:
Con DHCP snooping tutte le porte sono untrusted di default: su queste lo switch scarta i messaggi da server (OFFER, ACK, NAK), bloccando i DHCP server rogue. Si mettono "ip dhcp snooping trust" solo le porte verso i server legittimi (uplink).
Lo snooping costruisce la binding table (MAC, IP, VLAN, porta), riusata da Dynamic ARP Inspection e IP Source Guard.
reference: Exam topic 5.7 - DHCP snooping
[/Q]

Which information does Dynamic ARP Inspection (DAI) use to validate ARP packets received on untrusted ports?
options:
A) The CDP neighbor table
B) The DHCP snooping binding table
C) The routing table

[Q]
id: SEC-007
domain: 5
type: MULTI
text:
Which two statements about TACACS+ are true?
options:
A) It uses TCP port 49.
B) It encrypts only the password in the access-request packet.
C) It encrypts the entire body of the packet.
D) It combines authentication and authorization in one process.
E) It uses UDP ports 1812 and 1813.
answer: A, C
explanation:
TACACS+ (Cisco): TCP 49, cifra l'intero payload, separa authentication, authorization e accounting (ideale per l'amministrazione dei dispositivi e l'autorizzazione dei singoli comandi).
RADIUS (standard): UDP 1812/1813 (o 1645/1646), cifra solo la password, combina authentication e authorization; usato per l'accesso alla rete (802.1X, VPN).
reference: Exam topic 5.8 - Compare authentication, authorization, and accounting concepts
[/Q]

[Q]
id: SEC-008
domain: 5
type: SINGLE
text:
Which WPA3 feature replaces the Pre-Shared Key (PSK) exchange to protect against offline dictionary attacks?
options:
A) TKIP
B) Simultaneous Authentication of Equals (SAE)
C) WEP
D) 802.1X with EAP-TLS
answer: B
explanation:
WPA3-Personal usa SAE (Dragonfly handshake) al posto della PSK di WPA2: anche catturando l'handshake non si può fare un attacco a dizionario offline, e offre forward secrecy. WPA3 usa GCMP/AES, rende obbligatorio PMF (Protected Management Frames).
Evoluzione: WEP (RC4, rotto) → WPA (TKIP) → WPA2 (AES-CCMP) → WPA3 (SAE, GCMP).
reference: Exam topic 5.9 - Describe wireless security protocols (WPA, WPA2, and WPA3)
[/Q]

[Q]
id: SEC-012
domain: 5
type: SINGLE
text:
Which statement about "enable secret" compared to "enable password" is true?
options:
A) "enable password" is stored with a strong hash by default.
B) "enable secret" is stored as a hash and takes precedence if both are configured.
C) "service password-encryption" provides strong encryption equivalent to "enable secret".
D) Both commands are ignored if a console password is configured.
answer: B
explanation:
"enable secret" salva l'hash (MD5 type 5, oppure type 8/9 = SHA-256/scrypt sulle versioni recenti) e ha la precedenza su "enable password". "service password-encryption" applica solo il type 7, facilmente reversibile: nasconde le password a chi guarda lo schermo, ma non è sicurezza vera.
reference: Exam topic 5.3 - Device access control using local passwords
[/Q]

id: SEC-015

type: SINGLE
text:
Refer to the exhibit. Which statement about remote access to the router is true?
exhibit:
username admin privilege 15 secret Str0ngP@ss
!
line vty 0 4
 login local
 transport input ssh
 exec-timeout 5 0
options:
A) Telnet and SSH sessions are both allowed.
