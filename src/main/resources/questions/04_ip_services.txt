[Q]
id: IPS-001
domain: 4
type: SINGLE
text:
Refer to the exhibit. In NAT terminology, what is 203.0.113.5?
exhibit:
R1#show ip nat translations
Pro Inside global      Inside local       Outside local      Outside global
tcp 203.0.113.5:1025   10.1.1.10:51000    198.51.100.20:443  198.51.100.20:443
options:
A) Inside local
B) Inside global
C) Outside local
D) Outside global
answer: B
explanation:
- Inside local: indirizzo reale dell'host interno (10.1.1.10, privato)
- Inside global: come l'host interno appare all'esterno (203.0.113.5)
- Outside local / outside global: indirizzo dell'host esterno come visto dall'interno / come è realmente (qui coincidono: 198.51.100.20)
Trucco: "inside/outside" = DOVE si trova l'host; "local/global" = DA DOVE lo si guarda.
reference: Exam topic 4.1 - Configure and verify inside source NAT using static and pools
[/Q]

[Q]
id: IPS-002
domain: 4
type: SINGLE
text:
Which command configures PAT so that all inside hosts permitted by ACL 1 share the IP address of interface GigabitEthernet0/0?
options:
A) ip nat inside source static 10.1.1.0 interface GigabitEthernet0/0
B) ip nat outside source list 1 interface GigabitEthernet0/0
C) ip nat inside source list 1 interface GigabitEthernet0/0 overload
D) ip nat pool PAT interface GigabitEthernet0/0 overload
answer: C
explanation:
La parola chiave "overload" abilita PAT (NAT many-to-one con numeri di porta). Configurazione completa:
access-list 1 permit 10.1.1.0 0.0.0.255
interface g0/1 → ip nat inside
interface g0/0 → ip nat outside
ip nat inside source list 1 interface g0/0 overload
Errore tipico all'esame: dimenticare "ip nat inside/outside" sulle interfacce.
reference: Exam topic 4.1 - NAT/PAT
[/Q]

[Q]
id: IPS-003
domain: 4
type: SINGLE
text:
Which statement about NTP stratum is true?
options:
A) A higher stratum value indicates a more accurate time source.
B) Stratum 0 devices are reference clocks such as atomic or GPS clocks.
C) A Cisco router configured with "ntp master" always becomes stratum 0.
D) Stratum 16 is the most accurate stratum.
answer: B
explanation:
Lo stratum indica la distanza dalla sorgente di riferimento: stratum 0 = orologio di riferimento (GPS, atomico), stratum 1 = server collegato direttamente a esso, e così via. Più basso è il valore, più affidabile è la sorgente. Stratum 16 = non sincronizzato.
"ntp master [stratum]" rende il router sorgente autorevole (default stratum 8); "ntp server X" lo rende client.
reference: Exam topic 4.2 - Configure and verify NTP operating in a client and server mode
[/Q]

Place the DHCPv4 messages in the order in which they are exchanged when a client obtains an address.

DHCPDISCOVER => Step 1

[Q]
id: IPS-005
domain: 4
type: SINGLE
text:
DHCP clients in VLAN 10 must obtain addresses from a DHCP server located in a remote subnet. Where should the "ip helper-address" command be configured?
options:
A) On the DHCP server interface
B) Globally on the router
C) On the router interface (or SVI) that acts as the default gateway for VLAN 10
D) On the access switch port connected to the clients
answer: C

I DHCPDISCOVER sono broadcast e i router non inoltrano i broadcast. "ip helper-address <IP server>" sull'interfaccia che riceve i broadcast dei client (il loro gateway) li trasforma in unicast verso il server (DHCP relay agent), inserendo nel campo giaddr l'IP dell'interfaccia: così il server sa da quale pool assegnare l'indirizzo.
reference: Exam topic 4.6 - Configure and verify DHCP client and relay

Which SNMP version provides authentication and encryption of messages?

[Q]
id: IPS-008
domain: 4
type: FILL
text:
What decimal DSCP value corresponds to Expedited Forwarding (EF), commonly used for voice traffic? (Enter a number.)
answer: 46
explanation:
EF = DSCP 46 (binario 101110), per traffico voce a bassa latenza. Altri valori: CS0/default = 0, AF41 = 34 (video), CS3/AF31 = 24/26 (signaling), CS6 = 48 (routing).
Formula AFxy: DSCP = 8x + 2y (es. AF41 = 32 + 2 = 34).

[Q]
id: IPS-009
domain: 4
type: SINGLE
text:
Which queuing mechanism provides a strict-priority queue for delay-sensitive traffic such as voice, while other classes receive guaranteed bandwidth?
options:
A) FIFO
B) Weighted Random Early Detection (WRED)
C) Low Latency Queuing (LLQ)
D) Policing
answer: C
explanation:
LLQ = CBWFQ (code con banda garantita per classe) + una coda a priorità stretta (servita sempre per prima, ma limitata da un policer per evitare starvation delle altre code). WRED è congestion avoidance (scarta in modo casuale prima che la coda sia piena per evitare la TCP global synchronization).
reference: Exam topic 4.7 - QoS (queuing, congestion)
[/Q]

Which two statements about TFTP compared to FTP are true?

[Q]
id: IPS-013
domain: 4
type: MULTI
text:
Which two statements compare traffic shaping and traffic policing correctly?
options:
A) Shaping buffers excess traffic and sends it later.
B) Policing buffers excess traffic to smooth bursts.
C) Policing drops or re-marks traffic that exceeds the configured rate.
D) Shaping is typically applied inbound on an interface.
E) Shaping never introduces delay.
answer: A, C
explanation:
Shaping: mette in coda il traffico eccedente (introduce ritardo, nessuna perdita se il buffer basta), usato in uscita verso un provider con CIR inferiore alla velocità fisica.
Policing: scarta o rimarca il traffico eccedente, nessun buffer (nessun ritardo), applicabile in ingresso o uscita; tipico dei service provider in ingresso.
reference: Exam topic 4.7 - QoS (policing, shaping)
[/Q]

Which command configures a static NAT translation so that inside server 10.1.1.10 is reachable from the Internet as 203.0.113.10?
