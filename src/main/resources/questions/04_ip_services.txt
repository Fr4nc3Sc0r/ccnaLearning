Refer to the exhibit. In NAT terminology, what is 203.0.113.5?
exhibit:
R1#show ip nat translations
Pro Inside global      Inside local       Outside local      Outside global
tcp 203.0.113.5:1025   10.1.1.10:51000    198.51.100.20:443  198.51.100.20:443

A) Inside local
B) Inside global
C) Outside local

Which statement about NTP stratum is true?
options:
A) A higher stratum value indicates a more accurate time source.

C) A Cisco router configured with "ntp master" always becomes stratum 0.

Which queuing mechanism provides a strict-priority queue for delay-sensitive traffic such as voice, while other classes receive guaranteed bandwidth?
options:
A) FIFO
B) Weighted Random Early Detection (WRED)
C) Low Latency Queuing (LLQ)
D) Policing
answer: C

Which two statements compare traffic shaping and traffic policing correctly?

La sintassi è "copy <sorgente> <destinazione>": "copy running-config tftp:" chiede indirizzo del server e nome del file. "copy tftp: running-config" fa il contrario (unisce un file alla configurazione attiva). "copy running-config startup-config" (o "write memory") salva in NVRAM.
reference: Exam topic 4.9 - TFTP/FTP
[/Q]

How does a DHCP server determine from which pool to assign an address to a client whose request was forwarded by a relay agent?
options:
A) From the client MAC address
B) From the giaddr (gateway IP address) field inserted by the relay agent
C) From the TTL of the request
D) From the source port of the request

L'agente relay ("ip helper-address") scrive nel campo giaddr l'IP dell'interfaccia su cui ha ricevuto il broadcast del client. Il server sceglie il pool la cui subnet contiene il giaddr e invia la risposta al relay, che la consegna al client.

With PAT, many inside hosts share a single inside global IP address. How does the router distinguish return traffic for each host?
